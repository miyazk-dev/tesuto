# Nexora ローカルサイト

Astroで作成したNexora公式サイトのローカル開発用プロジェクトです。公開設定は未確定で、robots.txtは検索エンジンのクロールを拒否しています。

## 起動

Node.js 20.3以上を用意し、このフォルダーで次を実行します。

```sh
npm install
npm run dev
```

`http://localhost:4321/` を開きます。Astroの開発サーバーが変更を反映します。静的ビルドは `npm run build`、Astroの型・診断確認は `npm run check` です。

## Googleフォーム設定

1. 管理者のGoogleアカウントでGoogleフォームを作成します。質問項目は氏名または団体名（必須）、返信先メールアドレス（必須）、相談サービス（必須）、予算（任意）、希望納期（任意）、相談内容（必須）、プライバシーポリシーへの同意（必須）を想定しています。
2. フォームの公開・回答権限を確認し、公開用リンクを取得します。回答者に必要以上のGoogleアカウント情報を要求しない設定か確認してください。
3. フォームの「回答」から回答通知を有効にし、通知の受信先とテスト回答を確認します。回答の確認と返信はGmailから手動で行います。
4. `src/config/site.ts` の `contactFormUrl` に公開用リンクを設定します。ページ上のボタンはGoogleフォームを新しいタブで開きます。空欄のままなら準備中表示になります。

このプロジェクトはGoogleフォーム自体を作成せず、問い合わせデータを送信する独自バックエンドも持ちません。

## 設定とデータ

- `src/config/site.ts`: フォームURL、XアカウントURL、本番URLを一元管理します。空欄の値はサイト上にリンクや架空のURLとして出しません。
- `src/data/content.ts`: サービス、プロダクト、制作実績、仮価格、制作フローを管理します。公開プロダクトと掲載許可済み実績のみ掲載されます。
- SVGロゴ・favicon・OGP素材は `public/icons/` と `public/images/` にあります。Xプロフィール画像はロゴSVG、Xヘッダー画像レイアウトは `public/images/ogp.svg` を元に調整できます。

## 構成

`src/pages/` 各ページ、`src/components/` 共通ヘッダー・フッター、`src/layouts/` 共通SEOとレイアウト、`src/styles/` デザインシステム、`src/config/` 設定、`src/data/` 表示データ、`public/` ロゴと静的素材。

## ローカル確認について

このサイトは静的生成です。開発・検証段階ではインデックスを抑制する `public/robots.txt` を配置しています。canonical と sitemap は本番URLが確定していないため設定していません。
